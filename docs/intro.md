![The software development cycle](/img/image1.png)
*Fig 1.0: The software development cycle*

This document highlights the tech stack, architecture, environment, and best practices used for production. It also covers common pitfalls when engineering an app and pushing to production. This document is the culmination of the problems encountered, lessons learned, and things done right when building applications.

It roughly encompasses nearly **all aspects of the SDLC** except analysis and UI/UX Design. While this document provides detailed guidance on implementation, testing, and deployment, the SDLC overview helps contextualise how all these practices fit together in a full software lifecycle.

As you scroll through, this document gradually becomes more detailed — progressing from a high-level overview of the system architecture to increasingly specific implementation details, ultimately reaching code-level design, optimizations, and security aspects. This structure provides clear context before introducing technical complexity. A certain level of technical competency from the reader is assumed.

:::note
The contents of this document may change over time. Legacy or "unconventional" apps are not strictly required (though recommended) to follow everything here. Ensuring robust knowledge management is imperative — this document serves that exact purpose.
:::
